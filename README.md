# 🧬 CYP1A2 Pharmacogenomic Analysis Pipeline

[![Python](https://img.shields.io/badge/Python-3.14-blue)](https://python.org)
[![Status](https://img.shields.io/badge/Status-Complete-green)]()

A complete pharmacogenomic analysis pipeline studying the association between 
**CYP1A2 genotype** and **metabolizer status** using statistical and machine learning methods.

---

## 📊 Key Results

| Metric | Value |
|--------|-------|
| Chi-square (χ²) | 86.69 |
| p-value | 6.65 × 10⁻¹⁸ |
| Model Accuracy | 73.3% |
| Total Samples | 150 |
| Genotypes | AA, AG, GG |

---

## 🗺️ Pipeline Steps

- ✅ Data Loading & Inspection
- ✅ Exploratory Data Analysis (EDA)
- ✅ Data Quality Control
- ✅ Chi-square & Monte Carlo Tests
- ✅ Visualization (Heatmap & Bar Charts)
- ✅ Post-hoc Fisher's Exact Test
- ✅ Logistic Regression
- ✅ Random Forest & Cross Validation

---

## 🔬 Main Finding

> GG genotype → exclusively **Poor Metabolizers** (100%)  
> AG genotype → mixed **Intermediate & Poor**  
> AA genotype → predominantly **Intermediate Metabolizers**
